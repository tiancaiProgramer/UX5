# UX5

Windows 本地 AI 控制中心：集中配置思考 AI、执行 Agent、项目授权、Memory 和可选能力模块。

**当前发行：0.3.0 公开预览版，按全新安装提供。** 这不是稳定版；建议先在独立测试工程中体验并反馈问题。

## 下载与安装

前往 [Releases](https://github.com/tiancaiProgramer/UX5/releases)，下载 `UX5-0.3.0-preview-win-x64.zip`，不要下载 GitHub 自动生成的 Source code ZIP。

1. 使用 Windows 11 x64，准备至少 8 GB 可用空间。程序自带 .NET 运行时，不需要先安装 .NET SDK，也不需要虚拟机。
2. **完整解压**到一个新文件夹。`OpenCodeBridge.exe` 就是 **UX5 主程序**，名称沿用内部项目名；Worker 和 contract 文件必须与它放在一起，不要单独启动 Worker。
3. 普通双击 `OpenCodeBridge.exe`，点击小窗口里的“打开控制中心”（若浏览器已打开则直接使用新页面）。
4. 网页进入 **设置 → 运行环境与维护 → 系统与运行环境 → 安装**。确认网页提示，等待并亲自审核正常的 Windows UAC；准备可能有延迟，不要重复点安装。
5. 等明确显示安装完成。退出解压目录中运行的 UX5，再从桌面的 **UX5** 快捷方式打开安装版。
6. 按下面的 AI 配置步骤操作。安装完成与模型配置完成是两件事，没有凭据或模型时暂未就绪属于待配置状态。

完整步骤见 [新装指南](docs/INSTALL.md)；功能配置见 [配置与首次使用](docs/CONFIGURATION.md)。

## 第一次配置

- **执行 Agent**：在“AI 配置”中添加供应商、模型和相应 API Key，保存并选中该配置。使用服务商实际提供的 API 地址与模型名称。
- **思考 AI**：按界面支持的 API、CLI 或外部前端方式配置。它与执行 Agent 是两个独立位置，可以分别选择。
- **启动后台**：完成所需配置后，进入“设置 → 运行环境与维护 → 系统与运行环境”，点击“启动”，观察 OpenCode、模型凭据代理和 MCP 状态。
- **工程任务**：先在项目授权里选择一个具体测试目录及读取/编辑范围。官方 Codex 原生工程路径需要对应客户端可检测、已登录，并由本人审核项目授权。
- **日常使用**：回到工作台/对话，先完成一个小任务，再查看任务结果和 Memory 主题。可选模块按需开启，不必全部启用。

API Key 只填在本机 UX5 的凭据输入框中，不要提交到 Issue。外部 ChatGPT 等客户端中的聊天仍由该客户端管理，UX5 不会自动导入全部外部聊天历史。

## 当前范围与已知问题

- 这是**新装公开测试包**。其他系统版本、供应商和具体设备组合并未全部实测。
- 本机旧版迁移已完成写入提交和配置保留核验，但后台首次启动仍存在未解决问题。**已有 UX5 的用户先保留旧安装，不使用本预览包直接覆盖升级**；修复完成后另行公布支持范围。
- 官方 Codex 工程是支持方向；旧自研模块的原生命令执行继续禁用，不宣称所有模块和接入方式都已通过实际验收。
- Windows 安装过程需要当前桌面管理员账户审核正常 UAC；日常使用普通启动，不要把整个 UX5 长期以管理员身份运行。
- 发行包包含程序、Worker、契约、第三方声明和说明，不包含开发机的配置、密钥、日志、虚拟机或项目资料。

详见 [已知问题](docs/KNOWN-ISSUES.md)。
