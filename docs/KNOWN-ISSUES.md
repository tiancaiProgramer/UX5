# 当前预览版的已知问题

## 旧版迁移

本轮开发机旧安装已完成迁移提交、程序字节和配置保留核验，但后台首次启动仍失败。发现的两处缺失 NuGet 缓存目录已补齐，尚未证明这就是全部原因。

本 GitHub 版本按**新装公开测试版**提供。已有安装请保留原版本，不把本包当作已完成旧版覆盖升级验收的稳定版；后续修复会另行发布。

## 验证边界

当前构建的新装完整端到端流程尚未实际验收。后台首启问题已在旧版迁移场景发生，尚不能排除也影响部分新装设备；新装流程文档不是该流程已经全部通过的证明。

- 本包的升级/恢复定向夹具、模块生命周期检查及设备 SID/已知布局条件检查通过。
- 当前构建没有宣称在所有电脑、所有供应商或所有旧版本上实际安装/升级成功，也没有把旧构建的 Clean VM 结果记成当前构建全流程 PASS。
- 旧自研模块原生命令执行仍禁用。官方 Codex 工程需要有效客户端登录和本人项目授权。
- 当前接口提供的可选模块和外部前端仍处于预览阶段。
